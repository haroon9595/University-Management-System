# University-Management-System
A comprehensive C++ console-based application for managing university admissions with role-based access control, data persistence, and automated campus preference allocation.

  # Features
- **🔐 Role-Based Access** - Admin & Student portals
- **📊 Student Management** - Complete CRUD operations
- **🏫 Campus Allocation** - Automated preference system
- **🎨 Colorful UI** - Engaging console interface

  #  Usage Guide

# 🚀 Usage
